## Overview

CapyCalc is a browser-based utility for CapybaraGo players who want a faster way to organize builds and review character details. It brings together calculators, planning tools, and reference data so you can compare options without jumping between separate notes or spreadsheets.

The tool focuses on practical decision support: character sheet tracking, inheritance and specialization planning, damage and stat calculations, event and activity planning, game data lookup, and player card export. It is designed for use in the web platform and keeps the workflow centered on quick checks, planning, and record keeping.
